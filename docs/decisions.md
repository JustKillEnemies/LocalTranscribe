Начальные решения от 2026-10-08. «Принято» относится к направлению архитектуры,
не означает реализацию. Изменения фиксируются новой записью со ссылкой на
заменённое решение.

## Границы и отложенные решения

- ТЗ фиксирует стартовые модель/precision/VAD/чанки. Калибровка batch size,
  совместимые CUDA/cuDNN/ML-версии и размещение VAD проверяются на 06–07.
- Форматы экспорта, версии текста, поля семи таблиц, команды/события IPC и
  четыре экрана заданы полным ТЗ; конкретные адаптеры/DTO/реализация появляются
  по плану. Macro-этапы ТЗ сопоставлены шагам V2 без переименования корня.
- В 00 есть реальные проверки репозитория. Бизнес-тесты добавляются вместе с
  соответствующей логикой; фиктивные production-реализации не создаются.

Описание используемых стандартных интерфейсов:
[argparse Python 3.14](https://docs.python.org/3.14/library/argparse.html),
[importlib.metadata](https://docs.python.org/3.14/library/importlib.metadata.html),
[uv sync](https://docs.astral.sh/uv/concepts/projects/sync/).
Изолированный Python -I игнорирует PYTHON*; тесты явно задают -X utf8
для чтения русской справки на Windows. Это решение тестовой обвязки,
не изменение глобальных настроек Python. Фактические результаты — progress.md.
