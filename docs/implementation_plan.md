# План реализации 00–17

Источник последовательности —
[пользовательские промпты V2](CODEX_PROMPTS_V2.md).
План описывает будущую работу, не подтверждает реализацию.
Требования и расхождения — [requirements.md](requirements.md),
единственный источник статусов — [progress.md](progress.md).
[Оригинальное ТЗ](ORIGINAL_TZ.md) предоставлено;
[матрица требований и шагов](requirements_traceability.md) покрывает FR/NFR и
разделы без ID. Python закреплён: CPython 3.14 x64, >=3.14,<3.15.
Подготовка dev-окружения и lock отдельно разрешена владельцем при завершении 00,
она не означает реализации CLI/точки входа шага 01.

Каждый шаг выполняется отдельным запросом. Зависимость означает приёмку
предыдущего шага владельцем; документирование блокера само по себе не разрешает
продолжение. Переход с непройденными проверками требует явного решения владельца
и записи технического долга в progress. Авторизованный шаг и фактическая готовность фиксируются только в progress.md.

## Общие проверки и ограничения

- Каждый шаг включает соответствующий негативный сценарий и регрессионный
  тест выявленной ошибки; проверки должны быть изолированы от пользовательских данных.
- Реальные PostgreSQL/GPU/FFmpeg проверки обязательны только на шагах, где они
  предусмотрены; fake STT и unit-тесты не заменяют hardware/integration испытания.
- В отчёте: точная команда, PASS/FAIL/SKIP/NOT RUN, ограничения и READY/BLOCKED.
- Полное ТЗ предоставлено. План не заменяет его и не разрешает автоматически
  расширять требования; Python 3.14 окончательно выбран владельцем.
