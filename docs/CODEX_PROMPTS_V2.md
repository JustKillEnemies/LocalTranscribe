# Промпты Codex V2

Полный пользовательский документ находится в
[LocalTranscribe_Codex_Prompts_V2.md](LocalTranscribe_Codex_Prompts_V2.md).

Это указатель по имени, используемому в запросах и самом документе. Читать
исходный файл, включая постоянный контракт и запрошенный шаг. Указатель не
создаёт вторую копию промптов; исходник сохранён без изменений.

Промпты задают порядок работы, но не заменяют
[полное исходное ТЗ](ORIGINAL_TZ.md).
Последнее решение владельца: CPython 3.14 x64 с GIL, >=3.14,<3.15.
Устаревшие указания Python в исходных промптах исправлены только в двух местах;
остальная последовательность сохранена.
Нормализованные требования — [requirements.md](requirements.md),
единственный источник статусов и фактических проверок — [progress.md](progress.md).
