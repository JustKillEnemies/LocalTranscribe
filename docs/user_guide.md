# Краткое руководство LocalTranscribe

Подготовьте конфигурацию и БД по [windows_setup.md](windows_setup.md).
Запустите `LocalTranscribe.exe gui --env-file C:/private/app.env` либо exe без
аргументов для default user .env. Консоль этой onedir сборки оставляйте открытой
до выхода из приложения.

1. Добавьте/перетащите локальный файл, дождитесь ffprobe inspection.
2. Выберите настоящие аудиодорожки и при необходимости задайте ручные роли.
   Роли относятся к дорожке; автоматической диаризации двух голосов одной дорожки нет.
3. Выберите local model/cuda float16; для более экономного режима предусмотрен
   int8_float16. Проверьте свободный диск и параметры промежуточного аудио.
4. Запустите очередь. Pause/Resume работают через worker/checkpoints; Cancel
   сохраняет подтверждённые результаты. Закрытие не удаляет оригинальный файл.
5. Откройте результат: RAW неизменяем, READABLE — отдельная производная версия.
   Правки сохраняются новой MANUAL версией, черновик не выдаётся за сохранённый.
6. Поиск и фильтр дорожки помогают навигации. Переход к сегменту использует
   integer-ms шкалу оригинала. Выбор звука плеера отдельный от text stream filter.
7. Экспортируйте сохранённую версию TXT/Markdown/JSON. SRT требует привязки ко
   времени: для MANUAL без alignment выберите RAW/READABLE либо другой формат.

Если оригинальный файл перемещён/недоступен, сохранённые тексты и экспорт доступны;
воспроизведение потребует исходника. В PostgreSQL записан путь, а не видео.
Для удаления истории нужно явное подтверждение; удаление промежуточных файлов
включается отдельно. Исходные записи и неизвестные файлы не очищаются автоматически.

Типовые ошибки:

| Сообщение/симптом | Действие |
| --- | --- |
| FFmpeg/ffprobe не найден | Укажите absolute exe paths в .env, запустите doctor. |
| PostgreSQL недоступна/нет таблиц | Проверьте свою службу/роль/БД, затем db-upgrade и doctor. |
| Локальная модель не найдена | Подготовьте весь model directory отдельно, проверьте MODEL_PATH. |
| CUDA/DLL/OOM | Проверьте driver и целостность _internal/nvidia; при OOM выберите экономный режим. |
| Не хватает места | Освободите место в выбранном data/temp/export каталоге; источник не удаляйте. |
| Worker INTERRUPTED | Возобновите сохранённое задание с прежними model/VAD/source параметрами. |
| Не работает codec/player | Текст/экспорт остаются доступны; проверьте оригинал и codec на этой Windows. |

Точность не равна гарантии: публичный FLEURS benchmark и long-file measurements
описаны в [benchmark.md](benchmark.md). Важные имена, числа и термины проверяйте
по записи перед использованием транскрипта.
