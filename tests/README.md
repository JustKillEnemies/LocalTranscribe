# Тесты

Тесты располагаются здесь, вне src/local_transcriber. Бизнес-логики пока
нет. ШАГ 00 V2 добавляет test_repository_audit.py: реальные проверки структуры,
документов, Git-исключений и негативных сценариев, без production-заглушек.

Добавляйте unit-тесты вместе с реальной логикой, проверки адаптеров — при их
подключении. Domain и чистые правила должны проверяться без GUI, GPU и БД.
Маркеры integration и gpu зарегистрированы в pyproject.toml; конкретная
политика запуска будет определена при появлении таких тестов.

Из корня с доступным pytest: `python -B -m pytest -q -p no:cacheprovider`.
После подготовки dev-окружения: `uv run pytest`.
Тесты аудита не импортируют пакет и не реализуют smoke/CLI из шага 01.
Тесты будущей логики должны импортировать установленный local_transcriber;
обход src-layout через sys.path не предполагается.

Негативные сценарии проверяются на синтетических файлах в pytest tmp_path:
отсутствующий документ явно сообщает путь; повреждённый UTF-8 не принимается.
Содержимое синтетического пользовательского файла остаётся неизменным.
Дампы .backup и сжатый SQL включены как регрессия обнаруженного пробела .gitignore.
Оригинал ORIGINAL_TZ.md предоставлен. Дополнительно проверяются сохранность
FR/NFR-условий, полный перенос ТЗ, матрица всех требований/шагов, внутренние
ссылки и граница Python >=3.14,<3.15. Реальное распознавание пока не испытывается.

Для текущих проверок используйте активированную локальную .venv:
`python -m pytest -q`. При отказе доступа к общему Windows Temp задайте
PYTEST_DEBUG_TEMPROOT на новый уникальный каталог в игнорируемом tmp/;
безопасный пример — в корневом README.md. Не удаляйте чужой общий temp.
