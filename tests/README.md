# Тесты

Тесты располагаются здесь, вне src/local_transcriber. На этапе 0 бизнес-логики
нет, поэтому тестовые функции и фиктивные реализации не создаются.

Добавляйте unit-тесты вместе с реальной логикой, проверки адаптеров — при их
подключении. Domain и чистые правила должны проверяться без GUI, GPU и БД.
Маркеры integration и gpu зарегистрированы в pyproject.toml; конкретная
политика запуска будет определена при появлении таких тестов.

После установки dev-окружения из корня: `uv run pytest`.
Сейчас тестов нет, pytest возвращает код 5 (no tests collected).
Это не успешный прогон. Тесты будущего пакета должны импортировать установленный
local_transcriber; обход src-layout через sys.path не предполагается.
